# Code of Conduct

This project follows the Contributor Covenant code of conduct. We expect all
contributors and maintainers to be welcoming, respectful, and professional.

Key points
- Be respectful and considerate in all communications.
- Abuse, harassment, or discriminatory language will not be tolerated.
- Report violations to the maintainers or the security contact listed in SECURITY.md.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/


# Code of Conduct

This repository adheres to a contributor code of conduct to ensure a welcoming, respectful, and inclusive environment for all participants.

## Our standards

- Be respectful and assume good intentions.
- Use constructive language and avoid personal attacks.
- Respect differing viewpoints and work to find common ground.

## Unacceptable behavior

Examples of unacceptable behavior include harassment, hateful language, threats, doxxing, and sustained or severe disruption.

## Reporting

If you experience or witness unacceptable behavior, please report it to the maintainers by opening a private issue addressed to `security@your-org.example` (replace with your project's contact) or contacting the repository administrators directly.

For community-standard wording, consider adopting the Contributor Covenant Code of Conduct: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

<details>
<summary>Example reporting steps (expand)</summary>

1. Create a private issue named `SECURITY - Code of Conduct report` and describe the incident with timestamped evidence.
2. If the report contains sensitive personal data, avoid posting public logs and contact the maintainers via the private channel specified in the repository.
3. The maintainers will acknowledge receipt and follow-up within a few business days.

</details>

<details>
<summary>Enforcement and follow-up (expand)</summary>

Reports will be reviewed promptly and handled on a case-by-case basis. Consequences for violations may include warnings, removal of access, or referral to platform providers.

</details>

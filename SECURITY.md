# Security

If you discover a security vulnerability, please do not open a public issue. Instead, contact the maintainers privately:

- Email: security@localhost (replace with a real contact)

Steps for reporters
1. Provide a clear description of the issue and steps to reproduce.
2. Include affected versions and environment details.
3. If possible, include a minimal repro.

Maintainer response
- We aim to acknowledge reports within 3 business days and provide remediation plans.
